Engineering contracts behind the learning trace 학습 기록을 뒷받침하는 핵심 설계 규격

Traceable events추적 가능한 이벤트 설계

Proposed schema: event ID, learner ID, item, skill, time, correctness, and response time. Separates raw utterances from inferred skill labels. 이벤트 ID, 학습자 식별자, 문항, 스킬 분류, 타임스탬프, 정오답 및 응답 지연시간을 분리 저장하여 원본 발화와 모델의 추론 결과를 독립적으로 추적합니다.

Distinct estimates다차원 추정 알고리즘

DKT models sequence transitions; IRT estimates item discrimination and learner ability; decay functions calculate elapsed time memory retention. DKT는 시퀀스 연속성을, IRT는 문항 난이도와 잠재 능력을, 망각 모델은 시간 경과에 따른 기억 감쇠를 상호 보완적으로 계산합니다.

Learner-scoped retrieval학습자 범위 제한적 검색

Vector and relational queries are strictly scoped per learner tenant with immutable source audit tags. 벡터 및 관계형 검색은 개별 학습자의 테넌트 범위로 엄격히 제한되며, 생성된 모든 피드백에는 원본 참조 감사 태그가 부여됩니다.

Versioning and recovery버전 관리와 복구 메커니즘

Links event logs, learner states, and model checkpoint versions with idempotent retry handling for speech dropouts. 이벤트 로그와 지식 상태, 모델 가중치 버전을 1:1로 매핑하여 네트워크 불안정 시 멱등성을 보장하고 상태 왜곡을 복구합니다.

RQ02

Why do learners forget?학습자는 왜 망각하는가?

How does spacing optimize retention?학습 간격은 기억 유지에 어떤 영향을 주는가?

Do individual differences matter?개인차는 학습 곡선에 어떻게 작용하는가?

RQ06

Can retrieval practice minimize forgetting?인출 연습은 망각을 얼마나 방지할 수 있는가?

Active recall drills vs passive listening feedback ablation.능동적 발화 인출 훈련과 수동적 청취 피드백의 효능을 비교합니다.

RQ07

How to predict retention with Transformer KT?트랜스포머 기반 모델로 망각을 어떻게 예측할 것인가?

Separating exercise tokens from response tokens in continuous self-attention.자기주의 메커니즘에서 문항 임베딩과 응답 임베딩을 분리 인코딩합니다.

Published foundations and validation criteria 학술 연구 근거와 엄격한 검증 기준

Convergency — Engine Specification Preview

Website Release v5.3 · Converge Engine LTM v0.1 · Beta

LTM is a stateful long-term memory model for persistent context and traceable reasoning in AI x Education.

4-Stage Architecture Pipeline

1 / IngestSTT · Whisper Fine-Tuned for Non-Native Phonetics
2 / ParseGrammar Entity & Part-of-Speech Extraction
3 / LinkPersonalized Graph Linking & Context Correlation
4 / MemoryDKT + Forgetting Curve Decay (p=exp(-t/S)) + Redis/PostgreSQL

Inference Specs & Latency

FastAPI · Triton Inference Server 2x A10G · Model: GPT-4o Fine-Tuned + Neural TTS

End-to-End Latency Target: p95 820ms (STT 140ms + LTM 180ms + LLM 380ms + TTS 120ms)

Evaluation & Baselines

Prompt Generation Error Rate: 42% → 19% (Delta -23%p, p<0.01, n=2400)

Ablation Studies: w/o Forgetting -6%, w/o Knowledge Graph -8%, w/o DKT -11%

Data Corpus

1.2M Spoken Dialogue Sessions: Verb/Tense 34%, Preposition 22%, Article/Plural 18%, Copula 14%, Other 12%

API Standard

POST /v1/ltm/trace — Retrieve Context Vector & Memory State

POST /v1/policy/recommend — Recommend Next Adaptive Learning Item

Security: End-to-End Encryption, 90-Day Retention Policy, Zero Training on Customer Utterances.
